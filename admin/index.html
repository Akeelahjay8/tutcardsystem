Student Eligibility Roster

This turns TUT's official student list into the file the student portal checks every application against, so only real registered students can get past Step 2.

How this works — this file is static (read-only, not a live database), so it works for every student on every device, not just this computer. It just needs re-uploading whenever TUT gives you an updated list.
  1. Get the official student list from TUT as Excel (.xlsx), with at least a student number column and a surname column.
  2. Upload it below — it's converted in your browser only, nothing is sent anywhere.
  3. Click Download roster.json.
  4. Upload that roster.json file to your site so it sits in the same folder as your HTML files (drag into your GitHub repo).
  5. Done — the student portal will automatically start checking new applications against it.

Expected columns (name matching is flexible — e.g. "Student No", "StudentNo", "Student Number" all work): Student Number and Surname. Extra columns are ignored.
